# 注册海外 AI 账号前置准备：VPN · 接码 · 虚拟信用卡

> 注册 ChatGPT、Claude、Gemini 前必须搞定三件事。缺任何一件，注册流程都会卡住。

---

## 为什么需要这三样东西

海外 AI 平台对中国大陆用户设了三道墙：

| 门槛 | 具体表现 | 解决方案 |
|------|---------|---------|
| 网络限制 | 页面打不开，或打开后注册报错 | VPN（稳定节点） |
| 手机号限制 | +86 号码无法接收验证码 | 接码平台（虚拟海外号） |
| 支付限制 | 国内信用卡/银联被拒 | 虚拟信用卡 |

三件事**缺一不可**，而且有顺序依赖：没有 VPN 就打不开注册页面，没有海外号就过不了验证，没有虚拟卡就订阅不了付费版。

---

## 一、VPN（科学上网）

### 对 VPN 的要求

注册 AI 账号对 VPN 质量要求比日常使用高：

| 要求 | 原因 |
|------|------|
| **IP 纯净** | 机场共享 IP 可能被 OpenAI/Anthropic 标记为高风险 |
| **节点稳定** | 注册过程中断会导致账号异常 |
| **美国/日本/欧洲节点** | 香港/台湾节点对 ChatGPT 限制最严 |
| **全程同一节点** | 注册和后续使用保持同一地区，换节点容易触发风控 |

### 节点选择建议

- **优先选美国节点**（ChatGPT 和 Claude 对美国 IP 最友好）
- **避开香港、台湾、东南亚节点**注册 ChatGPT（OpenAI 已对这些地区限制）
- **Claude 可以用日本、欧洲节点**，相对宽松
- **Gemini 用美国节点**，Google 对中国 IP 最敏感

### 注册前必做：检查 IP 纯净度

打开 VPN 后，访问以下任一网址，确认 IP 信息：

```
https://ip.sb
https://whoer.net
https://ipinfo.io
```

重点看两项：
- **Country**：必须是美国/日本/欧洲，不能是 CN/HK
- **风险评分**（whoer.net）：低于 30% 为安全，高于 60% 很可能注册失败

> ⚠️ 如果 IP 显示为机房 IP（IDC/Datacenter），被拒概率更高。住宅 IP（Residential）通过率最高，但价格也最贵。

## 二、接码平台（虚拟海外手机号）

注册时需要收一条短信验证码（OTP），中国 +86 手机号在大多数海外 AI 平台已被屏蔽。

### 推荐平台对比

| 平台 | 价格（单次） | 特点 | 支付方式 |
|------|------------|------|---------|
| **SMS-Activate** | $0.1–$1 | 号码最多、最主流 | 支付宝 ✅ |
| **5sim.net** | $0.1–$0.5 | 界面简洁，支持多国 | 加密货币为主 |
| **SMSPOOL** | $0.1–$0.3 | 价格低，但成功率不稳定 | 加密货币 |
| **receive-smss.com** | 免费 | 公共号码，**风险极高** | 无需注册 |

**强烈推荐 SMS-Activate**——支持支付宝充值，号码供应量最大，是目前最稳定的选择。

### 操作步骤

**1. 注册 SMS-Activate**

访问 [sms-activate.io](https://sms-activate.io)，用邮箱注册账号。
备用链接：[hero-sms](https://hero-sms.com/cn/purchases/numbers)
**2. 充值（支持支付宝）**

点右上角"充值" → 选支付宝 → 最低充 $1–2 够用几次。

**3. 购买对应服务的号码**

左侧搜索栏输入要注册的服务名称（如 `OpenAI`、`ChatGPT`、`Anthropic`、`Google`）：

```
搜索 → 选国家（优先选美国/英国/加拿大）→ 购买
```

系统给你一个临时号码，有效期通常 **20 分钟**。

**4. 填入号码接收验证码**

在注册页面填写这个号码 → 点发送验证码 → 回到 SMS-Activate 等待接收 → 填入验证码完成验证。

> ⚠️ **注意事项：**
> - 买号后尽快操作，超时号码自动回收
> - 收不到短信可以点"再次发送"，最多等 3–5 分钟
> - 一个号码只能用一次，下次注册要重新买

### 哪些平台需要接码

| 平台 | 是否需要手机号 | 备注 |
|------|-------------|------|
| ChatGPT（OpenAI） | ✅ 必须 | +86 已屏蔽 |
| Claude（Anthropic） | ✅ 必须 | +86 已屏蔽 |
| Gemini（Google） | ❌ 不需要 | 用 Gmail 注册即可 |
| GitHub | ❌ 不需要 | 邮箱注册 |
| Cursor | ❌ 不需要 | 邮箱/Google 登录 |

## 三、虚拟信用卡

免费账号够用的话可以先跳过这一步。需要订阅付费版（ChatGPT Plus、Claude Pro 等）时才用。

### 背景：WildCard 已停止服务

2026 年初，最流行的 WildCard 虚拟信用卡平台已停止服务，目前主要替代方案：

| 平台 | 开卡费 | 月费 | 充值方式 | 适用范围 |
|------|--------|------|---------|---------|
| **Dupay** | 免费（Lite 卡）| 无 | USDT 充值 | OpenAI、Anthropic、Google 等 |
| **OneKey Card** | 免费 | 无 | USDT 充值 | 主流 AI 平台 |
| **Wise** | 免费 | 无 | 银行转账 | 需要真实海外地址验证 |
| **nobepay** | $1 | 无 | USDT 充值 | 支持较广 |

### 最简流程（以 Dupay 为例）

**1. 注册 Dupay**

访问 [dupay.one](https://dupay.one)，用邮箱注册，完成 KYC（身份验证）。

**2. 充值 USDT**

Dupay 只接受 USDT（稳定币）充值。购买 USDT 的方式：
- **欧易（OKX）**：国内用户最常用，支持支付宝/微信购买 USDT
- 买完后提币到 Dupay 地址（选 TRC20 链，手续费最低）

**3. 开卡 → 充值到卡**

USDT 入账后 → 申请虚拟 Visa/Mastercard → 把 USDT 换成美元充值到卡里。

**4. 订阅 AI 服务**

在 ChatGPT/Claude 的订阅页面填入卡号/有效期/CVV，账单地址用美国地址生成器随机生成一个即可。

> ⚠️ **账单地址建议**：用免税州地址（俄勒冈 OR、蒙大拿 MT），避免被收额外税费。可以用 [fakena.me](https://www.fakena.me) 生成。

### 各平台订阅价格参考（2026年5月）

| 服务 | 月费 | 年费折算 | 虚拟卡是否可用 |
|------|------|---------|-------------|
| ChatGPT Plus | $20 | $240/年 | ✅ Dupay/OneKey |
| Claude Pro | $20 | $240/年 | ✅ Dupay/OneKey |
| Gemini Advanced | $19.99 | $239/年 | ✅ 需绑 Google 账号 |
| Cursor Pro | $20 | $192/年（年付） | ✅ 支持支付宝直付 |

## 四、iOS / Android 订阅方案（无需虚拟卡的替代路径）

虚拟卡需要购买 USDT，流程相对繁琐。如果你用 iPhone 或 Android，可以走 App Store / Google Play 内购，**用支付宝或礼品卡付款**，完全绕开虚拟卡。

---

### 方案 A：iOS 美区 Apple ID + 礼品卡（稳定首选）

**适合**：iPhone/iPad 用户，追求稳定，对价格不敏感

#### 第一步：注册美区 Apple ID

> ⚠️ **必须用新邮箱注册全新账号**，不要把国区账号转美区（会影响已购 App 和 iCloud 数据）

**注册不需要 VPN，直接用国内网络操作即可。**

1. 打开浏览器（建议无痕模式），访问 [appleid.apple.com](https://appleid.apple.com) → **"创建你的 Apple ID"**

2. 填写基本信息：

   | 字段 | 填写要点 |
   |------|---------|
   | 名字 / 姓氏 | 英文，随意填 |
   | **国家 / 地区** | **必须选「美国」** |
   | 生日 | 年龄须 **≥ 18 岁** |
   | 电子邮件 | 用 Gmail 或 Outlook，**不要用 QQ / 163** |
   | 密码 | 8 位以上，含大小写+数字 |
   | 手机号 | **可以用 +86 国内号码** |

3. 验证邮箱（收 6 位码）→ 验证手机号（收短信码）

4. **账单地址（关键）**：
   - 付款方式选 **"None（无）"**
   - 地址选免税州：**俄勒冈（Oregon）** 或 **蒙大拿（Montana）**，可用 [fakena.me](https://www.fakena.me) 一键生成
   - 电话填 fakena.me 生成的当地号码即可

5. 点击继续，账号创建完成

> ✅ **登录 App Store 只在「媒体与购买项目」里登录，不要在 iPhone 「设置→Apple ID」里换账号**，否则 iCloud 会切换，影响已有数据。

#### 第二步：购买美区 App Store 礼品卡

以下渠道均支持**支付宝付款**：

| 渠道 | 说明 | 链接 |

| **bewild.ai** | 第三方代充，更省心，直接帮你完成订阅 | [bewild.ai/subscribe](https://bewild.ai/subscribe) |

> 💡 **嫌麻烦？选 bewild.ai**：不用自己操作礼品卡兑换和订阅流程，付人民币直接搞定。
>
> 自己买卡建议面值 **$25**（订阅 $20 后还有余额备用）。

#### 第三步：兑换礼品卡 + 登录 App Store

1. iPhone 打开 `App Store` → 右上角头像
2. 滑到底部 → **「退出登录」**（退出国区账号）
3. 重新登录美区 Apple ID
4. 头像 → **「兑换礼品卡或代码」** → 输入卡码，余额到账

#### 第四步：下载 App 并订阅

在美区 App Store 搜索 ChatGPT 或 Claude → 安装 → App 内点升级 → 用 Apple ID 余额支付。

> ⚠️ **Claude 订阅关键**：Claude 账号的注册邮箱必须与美区 Apple ID 邮箱**完全一致**，否则订阅失败或被封。

**价格参考（美区）**：ChatGPT Plus $20/月，Claude Pro $20/月

### 方案 B：iOS 土区 Apple ID + 礼品卡（便宜约 45%）

**适合**：追求低价，愿意多操作几步

土耳其区 ChatGPT Plus 约 ₺500（约 **¥100/月**），比美区 $20（约 ¥145）便宜将近一半。

**推荐方式：先注册国区账号，再通过专用页面转区到土耳其**（比直接注册土区更稳定）。

---

#### 第一阶段：注册中国大陆 Apple ID

1. 访问 [appleid.apple.com](https://appleid.apple.com) → 创建 Apple ID
2. 国家/地区选**中国大陆**，用 Gmail/Outlook 邮箱注册
3. 手机号填 +86 国内号码，完成邮箱 + 手机验证
4. 账号注册完成（此时是国区账号）

---

#### 第二阶段：网页端转区到土耳其

> ⚠️ **此阶段必须开 VPN，且必须是全局模式**（不是分流/规则模式）。节点选美国或欧洲，不要用土耳其节点。

1. 开启 VPN 全局模式，确认 IP 为非中国
2. 浏览器访问土耳其专用管理页面：**[account.apple.com/tr/](https://account.apple.com/tr/)**
3. 用刚注册的 Apple ID 登录
4. 进入 **「个人信息」** → 找到「国家/地区」→ 点 **「更改」**
5. 填写以下信息：

   | 字段 | 填写要点 |
   |------|---------|
   | 付款方式 | **选 None（无）**，不绑信用卡 |
   | 街道地址 | 填伊斯坦布尔地址（用 [1ktools.com](https://www.1ktools.com) 生成） |
   | 城市 | **Istanbul** |
   | 省/州 | İstanbul |
   | 邮编 | 34000（或生成器提供的真实邮编） |
   | 电话 | 保留原有 **+86 国内手机号**即可 |

6. 点击保存，页面显示国家变为 **Türkiye（土耳其）** → 转区成功

> 💡 如果「付款方式」里没有 None 选项，说明 VPN 没有全局代理，代理软件切到「全局模式」后刷新重试。

---

#### 第三阶段：手机端切换 App Store 到土区

1. iPhone 打开 `App Store` → 头像 → 滑到底部 → **退出登录**
2. 重新登录刚转区的土区 Apple ID
3. App Store 首页应变为土耳其界面（显示土耳其语 / TL 价格）
4. **立即下载一个免费 App**（如 YouTube），把店面锁定在土区

> ⚠️ 使用土区账号浏览和下载 App 时，**VPN 节点选非土耳其的节点**（美国 / 欧洲），否则部分 App 可能无法正常使用。

## 五、注册前完整检查清单

每次注册新账号前，按顺序确认：

```
□ VPN 已开，节点为美国/日本/欧洲
□ ip.sb 显示 IP 非中国，风险评分低
□ 浏览器已开无痕/隐身模式
□ SMS-Activate 已充值，余额足够
□ 邮箱准备好（推荐 Gmail，不要用 QQ/163）
□ 全程保持同一个 VPN 节点不切换
```

### 邮箱选择

| 邮箱 | 推荐度 | 原因 |
|------|--------|------|
| Gmail | ⭐⭐⭐⭐⭐ | 最通用，ChatGPT/Claude 直接认可 |
| Outlook/Hotmail | ⭐⭐⭐⭐ | 注册容易，也很通用 |
| ProtonMail | ⭐⭐⭐ | 隐私好，但部分平台会拒绝 |
| QQ/163/126 | ❌ | 大多数海外平台不接受 |

> Gmail 本身也需要接码注册，详见下一篇：[Google 账号注册全流程](./google-account-register)

## 六、常见失败原因速查

| 现象 | 原因 | 解决方法 |
|------|------|---------|
| 注册页面打不开 | VPN 未开或节点不稳定 | 换节点重试 |
| 提示"此地区不支持" | 节点 IP 被识别为中国/香港 | 换美国节点 |
| 手机号"已被使用" | 买到了旧号（别人用过） | 换一个号重新买 |
| 收不到短信 | 号码已过期或平台拒绝该号 | 退款重买，换美国/英国号 |
| 信用卡被拒 | 卡余额不足或被风控 | 确认余额、换卡重试 |
| 注册成功但登录被封 | 注册和登录用了不同 IP 地区 | 始终用同一地区节点 |
| 订阅成功但扣款失败 | 账单地址填写不规范 | 用免税州真实格式地址 |
