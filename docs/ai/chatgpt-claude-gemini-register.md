## 一、ChatGPT 注册与订阅

### 1.1 注册流程

1. 开 VPN（**美国节点**，避开香港/台湾/东南亚）
2. 访问 [chatgpt.com](https://chatgpt.com) → 点 "Sign up"
3. 选择注册方式（推荐 **Continue with Google**，用 Gmail 一步搞定）
4. 如果选邮箱注册：填 Gmail → 设密码 → 验邮件
5. **手机号验证**：+86 已被屏蔽，需要接码平台
   - SMS-Activate 搜索 "OpenAI" 或 "ChatGPT"
   - 选美国/英国号码（约 $0.5-1）
   - 填入号码 → 接收验证码 → 完成
6. 注册完成后直接进入聊天界面

> ⚠️ **节点选择关键**：OpenAI 对 IP 有严格检测，机场共享 IP 被封概率较高。遇到"Access denied / not available in your country"，换一个不同的美国节点重试。

### 1.2 免费版限制

| 功能 | 免费版 |
|------|--------|
| 模型 | GPT-4o mini（较弱）|
| 消息数量 | 有每日限额（约 10-20 条）|
| GPT-5 | ❌ |
| 图像生成（DALL-E）| ❌ |
| 文件上传分析 | 有限 |
| 联网搜索 | 有限 |

### 1.3 订阅 ChatGPT Plus（$20/月）

**方式一：iOS 美区礼品卡（最简单）**

1. 注册美区 Apple ID（详见[前置准备](./ai-account-prerequisites#方案-a-ios-美区-apple-id--礼品卡稳定首选)）

- 不要和他人共享账号（OpenAI 有设备检测）
- Plus 账号异地登录会要求重新验证

## 二、Claude 注册与订阅

> Claude 是目前风控最严的平台，Anthropic 对中国 IP 的检测极其激进。操作要更谨慎。

### 2.1 注册流程

1. 开 VPN（**美国节点，不要用香港/亚洲节点**）
2. 访问 [claude.ai](https://claude.ai) → 点 "Sign up"
3. 强烈推荐 **Continue with Google**（用 Gmail 注册，风控通过率更高）
4. 如用邮箱注册：填 Gmail → 验邮件
5. **手机号验证**：
   - SMS-Activate 搜索 "Anthropic" 或 "Claude"
   - 选美国号码（约 $0.5-1）
   - 填入 → 接收验证码
6. 完成注册

> ⚠️ **Claude 封号预警信号**：
> - 注册成功但马上提示"你的账号因违反服务条款已被暂停"
> - 说明注册时 IP 风险过高，换更干净的 VPN 节点重新注册一个账号

### 2.2 免费版限制

| 功能 | 免费版 |
|------|--------|
| 模型 | Claude Sonnet（较弱）|
| 消息数量 | 每天约 10-20 条，用完要等重置 |
| Claude Opus（最强模型）| ❌ |
| 文件上传 | ✅ 有限制 |
| Projects（项目记忆）| ❌ |

### 2.3 订阅 Claude Pro（$20/月）

Claude 的风控延伸到订阅环节——用什么方式订阅，比其他平台要求严得多。

**⭐ 黄金法则：Claude 账号邮箱必须与订阅所用的 Apple ID 邮箱完全一致**

**方式一：iOS 美区 Apple ID（最推荐）**

1. 注册一个**与 Claude 账号同邮箱**的美区 Apple ID
   - 例：Claude 账号是 `abc@gmail.com`，Apple ID 也必须是 `abc@gmail.com`
2. iPhone 切换到这个美区 Apple ID
3. 在 [Pockyt](https://shop.pockyt.io/pc/goodsDetail/vc1aYhc/App%20Store%20&%20iTunes%20USA/all) 购买美区礼品卡 $25（支付宝付款）
4. 下载 Claude App → 内购订阅 Pro

> 或直接用 [bewild.ai](https://bewild.ai/subscribe) 代充，更省心。

> 这是目前成功率最高的方式，风控最少。

**方式二：虚拟信用卡（风险较高）**

Anthropic 对虚拟卡有一定识别，但 Dupay 和 OneKey 仍可用：
1. 访问 [claude.ai](https://claude.ai) → 升级 Pro → 填写卡信息
2. 如果被拒，尝试更换节点后重新提交

**方式三：Android Google Play**

与 ChatGPT 相同流程，需要 Google Play 绑定虚拟卡。

### 2.4 防封号关键操作

- **注册前解绑中国手机号**：如果之前绑过 +86，在订阅前到账号设置里删除
- **始终用同一美国节点**，不要在不同地区 IP 登录
- **不要共享账号**，Anthropic 的设备检测比 OpenAI 更严
- **订阅成功后**，把 VPN 地区固定下来，换 IP 可能触发重新验证

## 三、Gemini 注册与订阅

Gemini 就是 Google 账号，注册最简单，风控也最宽松。

### 3.1 "注册"流程

有了 Google 账号就有了 Gemini，不需要额外注册：

1. 开 VPN
2. 访问 [gemini.google.com](https://gemini.google.com)
3. 用 Google 账号登录
4. 完成简单的地区设置即可使用

> Google 在中国被完全屏蔽，但只要开了 VPN，Gemini 使用体验是三者中最顺畅的——很少有 IP 风控问题。

### 3.2 免费版功能

Gemini 免费版相当慷慨：

| 功能 | 免费版 |
|------|--------|
| 模型 | Gemini 2.0 Flash |
| 消息数量 | 较宽松，无严格每日限制 |
| Google 服务集成 | ✅（Gmail、Docs、Drive）|
| 图像生成（Imagen）| ✅ 有限 |
| Gemini 2.5 Pro | ❌ |

### 3.3 订阅 Gemini Advanced（$19.99/月）

Gemini Advanced 包含在 **Google One AI Premium** 套餐里：

**方式一：虚拟信用卡直接订阅**

1. 访问 [one.google.com](https://one.google.com) → 选 AI Premium 套餐
2. 填写 Dupay / OneKey 虚拟卡
3. 账单地址用美国免税州地址

**方式二：Android Google Play**

Google Play 已绑定虚拟卡 → 在 Gemini App 内直接升级。

**方式三：iOS 无法内购**

Google 旗下服务在 iOS 上不提供 App 内购（为了绕开苹果 30% 抽成），必须通过网页订阅。

### 3.4 Gemini 的特殊优势

- 集成 Google Workspace：可以直接分析 Gmail、总结 Google Docs、搜索 Drive 文件
- 在 Google 系产品（Chrome、Android）里原生集成
- 对中国用户的封号风险最低（只要 VPN 稳定基本没问题）
