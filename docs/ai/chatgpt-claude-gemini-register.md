## 一、ChatGPT 注册与订阅

### 1.1 注册流程

1. 开 VPN（**美国节点**，避开香港/台湾/东南亚）
2. 访问 [chatgpt.com](https://chatgpt.com) → 点 "Sign up"
3. 选择注册方式（推荐 **Continue with Google**，用 Gmail 一步搞定）
4. 如果选邮箱注册：填 Gmail → 设密码 → 验邮件
5. **手机号验证**：+86 已被屏蔽，需要接码平台
   - 打开 HeroSMS（`hero-sms.com`）或 5sim 搜索 "OpenAI" / "ChatGPT"（原 SMS-Activate 已于 2025 年底关停）
   - 选美国/英国号码（约 $0.5-1）
   - 填入号码 → 接收验证码 → 完成
6. 注册完成后直接进入聊天界面

> ⚠️ **节点选择关键**：OpenAI 对 IP 有严格检测，机场共享 IP 被封概率较高。遇到"Access denied / not available in your country"，换一个不同的美国节点重试。

### 1.2 免费版与套餐对比

| 功能 | 免费版 | Go（$8/月） | Plus（$20/月） |
|------|--------|------------|---------------|
| 基础模型 | 轻量级旗舰（如 GPT-6 Luna） | 同免费版，额度更高 | 解锁高阶推理模型（如 Sol / Astra） |
| 消息与上下文 | 有频率限制 | 限额大幅放宽 | 高额度 + 更长上下文 |
| 原生图像生成 | ✅ 每日有限额度 | ✅ 更高额度 | ✅ 高额度 |
| 文件上传 / 联网搜索 | 有限 | 放宽 | 完整（含深度研究、Codex） |
| 广告展示 | 部分地区可能展示 | 部分地区可能展示 | 无广告 |

> 重度开发者/研究者还可选 **Pro（$100 / $200 / $500/月）** 多档位套餐。

### 1.3 订阅 ChatGPT Plus（$20/月）

**方式一：iOS 美区礼品卡（最简单、最稳定）**

1. 注册美区 Apple ID（详见[前置准备](./ai-account-prerequisites#方案-a-ios-美区-apple-id--礼品卡稳定首选)）
2. 用支付宝在 [Pockyt](https://shop.pockyt.io/pc/goodsDetail/vc1aYhc/App%20Store%20&%20iTunes%20USA/all) 购买美区礼品卡 $25
3. iPhone 下载 ChatGPT App → 内购订阅 → 用 Apple ID 余额支付

> 嫌麻烦可以直接用 [bewild.ai](https://bewild.ai/subscribe) 代充，支付宝付人民币，省去礼品卡兑换步骤。

**方式二：iOS 土区礼品卡（便宜约 45%）**

1. 注册土区 Apple ID
2. 在 [MTCGame](https://www.mtcgame.com/apple-store/itunes-hediye-karti) 购买土耳其区礼品卡（支持支付宝）
3. iPhone 切换土区 App Store → 下载 ChatGPT → 订阅

> 土区价格随汇率波动，通常比美区便宜不少。

**方式三：虚拟信用卡直接订阅（网页端）**

1. 准备可用的美区虚拟 Visa 卡（如 CoreGold / PokePay 等，**注意 Dupay、OneKey Card、WildCard 均已停服**），按需小额充值 $25 左右
2. 访问 [chatgpt.com](https://chatgpt.com) → 左下角升级 → 填写卡信息
3. 账单地址用美国免税州（俄勒冈/蒙大拿）

**方式四：Android Google Play**

Google Play 绑定境外卡/可用虚拟卡或充值美区 Google Play 礼品卡 → 打开 ChatGPT App → 内购订阅。

### 1.4 使用注意事项

- 固定使用**同一地区的 VPN 节点**，频繁切换会触发风控
- 不要和他人共享账号（OpenAI 有设备检测）
- Plus 账号异地登录会要求重新验证

## 二、Claude 注册与订阅

> Claude 是目前风控最严的平台，Anthropic 对中国 IP 的检测极其激进。操作要更谨慎。

### 2.1 注册流程

1. 开 VPN（**美国节点，不要用香港/亚洲节点**）
2. 访问 [claude.ai](https://claude.ai) → 点 "Sign up"
3. 强烈推荐 **Continue with Google**（用 Gmail 注册，风控通过率更高）
4. 如用邮箱注册：填 Gmail → 验邮件
5. **手机号验证**：
   - 打开 HeroSMS（`hero-sms.com`）或 5sim 搜索 "Anthropic" / "Claude"
   - 选美国号码（约 $0.5-1）
   - 填入 → 接收验证码
6. 完成注册

> ⚠️ **Claude 封号预警信号**：
> - 注册成功但马上提示"你的账号因违反服务条款已被暂停"
> - 说明注册时 IP 风险过高，换更干净的 VPN 节点重新注册一个账号

### 2.2 免费版与套餐对比

| 功能 | 免费版 | Pro（$20/月） | Max（$100/月）/ Ultra（$200/月） |
|------|--------|--------------|--------------------------------|
| 模型 | 基础主力模型（Sonnet） | 含 Opus 等旗舰模型 | 旗舰模型 + 更高阶推理档位 |
| 用量限制 | 每 5 小时及每周有限额 | 5 小时滚动限额 + 周限额 | 5x / 10x Pro 额度 + 附赠等值 API 额度 |
| Claude Code / Projects | 有限 / 不含完整额度 | ✅ 支持 | ✅ 高频开发首选 |

### 2.3 订阅 Claude Pro（$20/月，年付 $17/月）

Claude 的风控延伸到订阅环节——用什么方式订阅，比其他平台要求严得多。

**⭐ 黄金法则：Claude 账号邮箱必须与订阅所用的 Apple ID 邮箱完全一致**

**方式一：iOS 美区 Apple ID（最推荐）**

1. 注册一个**与 Claude 账号同邮箱**的美区 Apple ID
   - 例：Claude 账号是 `abc@gmail.com`，Apple ID 也必须是 `abc@gmail.com`
2. iPhone 切换到这个美区 Apple ID
3. 在 [Pockyt](https://shop.pockyt.io/pc/goodsDetail/vc1aYhc/App%20Store%20&%20iTunes%20USA/all) 购买美区礼品卡 $25（支付宝付款）
4. 下载 Claude App → 内购订阅 Pro

> 或直接用 [bewild.ai](https://bewild.ai/subscribe) 代充，更省心。

> 这是目前成功率最高的方式，风控最少。

**方式二：虚拟信用卡（风险较高）**

Anthropic 对预付/虚拟卡识别极严，仅少数高权重美区 Visa 卡段（如 CoreGold 等，**Dupay / OneKey 已停服**）偶可通过：
1. 访问 [claude.ai](https://claude.ai) → 升级 Pro → 填写卡信息
2. 如果被拒，优先改用方式一（iOS 美区礼品卡）

**方式三：Android Google Play**

与 ChatGPT 相同流程，通过 Google Play 余额/礼品卡或绑定的可用卡片内购。

### 2.4 防封号关键操作

- **注册前解绑中国手机号**：如果之前绑过 +86，在订阅前到账号设置里删除
- **始终用同一美国节点**，不要在不同地区 IP 登录
- **不要共享账号**，Anthropic 的设备检测比 OpenAI 更严
- **订阅成功后**，把 VPN 地区固定下来，换 IP 可能触发重新验证

## 三、Gemini 注册与订阅

Gemini 就是 Google 账号，注册最简单，风控也最宽松。

### 3.1 "注册"流程

有了 Google 账号就有了 Gemini，不需要额外注册：

1. 开 VPN
2. 访问 [gemini.google.com](https://gemini.google.com)
3. 用 Google 账号登录
4. 完成简单的地区设置即可使用

> Google 在中国被完全屏蔽，但只要开了 VPN，Gemini 使用体验是三者中最顺畅的——很少有 IP 风控问题。

### 3.2 免费版功能

Gemini 免费版相当慷慨（注：旧版 Gemini 2.0 Flash 已于 2026 年 6 月停服，当前网页版与 API 均已切换至新一代 Gemini 3.x / 4 系列）：

| 功能 | 免费版 |
|------|--------|
| 模型 | 最新一代 Flash 系列（轻量高速） |
| 消息数量 | 较宽松，无严格每日限制 |
| Google 服务集成 | ✅（Gmail、Docs、Drive）|
| 图像生成 | ✅ 有限额度 |
| 高阶旗舰与 Deep Think 深度思考 | 限量或需订阅 Google AI Pro / Ultra |

### 3.3 订阅 Google AI Pro（$19.99/月，原 Gemini Advanced）

原 **Gemini Advanced / Google One AI Premium** 现已整合升级为 **Google AI Pro**（$19.99/月）及更高阶的 **Google AI Ultra** 套餐：

**方式一：虚拟信用卡 / 境外卡网页订阅**

1. 访问 [one.google.com](https://one.google.com) → 选择 Google AI Pro 套餐
2. 填写可用的美区虚拟 Visa 卡（如 CoreGold / PokePay）或真实境外卡
3. 账单地址用美国免税州地址

**方式二：Android Google Play**

Google Play 绑定可用卡片或充值 Google Play 礼品卡 → 在 Gemini App 内直接升级。

**方式三：iOS 无法内购**

Google 旗下服务在 iOS 上通常不提供 App 内购（为了绕开苹果 30% 抽成），建议通过网页端订阅。

### 3.4 Gemini 的特殊优势

- 集成 Google Workspace：可以直接分析 Gmail、总结 Google Docs、搜索 Drive 文件
- 在 Google 系产品（Chrome、Android）里原生集成
- 对中国用户的封号风险最低（只要 VPN 稳定基本没问题）

如果你只想免费使用，三者各有特点：

**三个都注册上，根据任务按需切换**，是最划算的方式。
